# 巨构唤醒 Megastructure Awakening

第三人称 3D 解谜 Demo（Godot 4.7.2）。在浮空花园里校准三座岛屿的机关，唤醒中央巨构。

**在线游玩**：打开本仓库的 GitHub Pages 页面（电脑上的 Chrome / Edge，需要 WebGL 2；首次加载约 90 MB）。

## 操作
| 按键 | 作用 |
|---|---|
| 鼠标 | 转动视角（先点一下画面锁定鼠标） |
| W A S D / 空格 | 移动 / 跳跃 |
| E | 与机关、镜子互动；镜面视图里试射 |
| 1–4 | 选择光环 / 砝码 / 镜子 |
| Q / R | 转动光环或镜面；西岛：砝码左右挪一格 |
| Z | 北岛第二层：撤销上一步 |
| 退格 | 重置当前机关 |
| Esc | 离开机关 / 跳过结尾演出 / 暂停 |
| F2 | 切换主角外观：狐狸 ↔ 萨摩耶（测试版） |

网页版使用兼容渲染，画面比 Windows 版简化。
