# 巨构唤醒 Megastructure Awakening

第三人称 3D 解谜 Demo（Godot 4.7）。在浮空花园里校准三座岛屿的机关，唤醒中央巨构。

**在线试玩**：https://e874146441-hue.github.io/megastructure-awakening/

## 可玩范围

- 完整流程：中央大厅 → 北岛、西岛、东岛（顺序不限）→ 启动核心 → 结尾演出 → 继续探索。
  - 北岛：三环联动。
  - 西岛：力矩配重。
  - 东岛：5 段光路折射。
- 主菜单的「东岛光路试玩」是早期做的独立东岛切片（旧版 E1/E2：镜子转到位就过关，没有试射）；完整的东岛请从「开始新游戏」进入。
- 关卡、机关规则、解法和反馈与 Windows 版一致。

## R8 更新（东岛 E2）

- E2 镜座旁原地转身、贴着镜座走、进出镜面视图时，镜头不再被镜座和门柱夹住（挡住狐狸的镜座外壳淡出，镜面半透明保留轮廓）。
- 静音也能分辨试射结果：金色短虚线是预瞄；按 E 后有一条连续光束飞出去；打偏时光束从接收器旁擦过；第一次命中时光束在接收器处变成薄荷色、接收器亮一半、镜座「Ⅱ」旁两个圆点亮一个；第二次命中两个圆点全亮，桥才升起。
- 退出 E2 镜面视图后，镜头朝向接收器和桥头。
- 桥头铜槽、接收器底座、露台门槛重做了近景细节。
- 手机横屏时，E2 镜面视图里的按钮会自动避开镜子、圆点和瞄准线。

## 支持的操作

### 电脑（键盘 + 鼠标）

| 按键 | 作用 |
|---|---|
| 鼠标 | 转动视角（先点一下画面锁定鼠标） |
| W A S D / Shift / 空格 | 移动 / 加速 / 跳跃 |
| E | 与机关、镜子互动；镜面视图里试射 |
| 1–4 | 选择光环 / 砝码 / 镜子 |
| Q / R | 转动光环或镜面；西岛：砝码左右挪一格 |
| Z | 北岛第二层：撤销上一步 |
| 退格 | 重置当前机关 |
| Esc | 离开机关 / 跳过结尾演出 / 暂停 |
| F2 | 切换主角外观：狐狸 ↔ 萨摩耶（造型测试） |

### 手机 / 平板（横屏，纯触控）

- 左半屏按住拖动：移动。
- 右半屏拖动：转视角。
- 「跳」：跳跃。
- 靠近机关时出现互动按钮。
- 进入机关后，按钮跟着提示出现：数字选部件、左转 / 右转（西岛为 ← →）、试射、撤销、重置、返回。
- 右上角：暂停、换装；结尾演出时是跳过。
- 手机上会自动降低阴影距离、粒子数量和 3D 渲染分辨率，浮岛轮廓、光路、接收器和桥面提示保持不变。

## 加载与画质

- 首次加载约 35 MB（压缩传输），之后浏览器会缓存。
- 网页版使用 WebGL 2 兼容渲染，画面比 Windows 版简化。
- 推荐浏览器：Chrome、Edge 最新版。
